Árbol TF
========

.. clip:: tf_tree

El árbol TF del robot, como ``rqt_tf_tree``. Se actualiza cada 2 segundos.

* Los frames estáticos tienen el borde discontinuo; cada frame dinámico muestra hace cuánto se
  actualizó, en naranja cuando pasa más de 5 segundos sin actualizarse.
* Toca un frame para ver su padre y hace cuánto se actualizó.
* Pellizca para hacer zoom, arrastra para moverte y toca dos veces para verlo entero.

En el móvil también está en Inicio, sin crear una pestaña. En el PC, haz zoom con la rueda del ratón
y doble clic para verlo entero.
