Contact and support
===================

Found a bug or have an idea?
   Write to `jc.manzanares.serrano@gmail.com <mailto:jc.manzanares.serrano@gmail.com?subject=VizMini2>`_.
   From the app, **Home → Contact and bug reports** opens an email with the app version, Android
   version and phone model already filled in: just add what happened. From the PC, write to the
   same address and include the app version (in the window title), your operating system (Ubuntu
   or Windows version) and the robot's ROS 2 distribution.

Support the project
   VizMini2 is free and built in my spare time. If it helps you with your robots, you can support
   it on `GitHub Sponsors <https://github.com/sponsors/Juancams>`_. Thank you!
