Contributing
============

Bug reports, ideas and pull requests are welcome.

* **License.** The code is under the GNU GPL version 3, with an additional permission to combine
  it with Google Play Services and Firebase (``LICENSE`` and ``NOTICE``). The name "VizMini2" and
  its logo are not covered by the license: forks must use their own.
* **Contributor agreement.** Every contribution is accepted under ``CLA.md``: add the line it asks
  for to your first pull request.
* **Headers.** New source files start with the same copyright and ``SPDX-License-Identifier:
  GPL-3.0-only`` header as the others (``tools/license_headers.py`` checks it).
* **Language.** Code and comments in English. Texts the user sees go to
  ``app/src/main/res/values*/strings*.xml``, in English and Spanish; the desktop app reads the
  same files.
* **Commits.** English, ``Area: description`` (for example ``RViz: resizable image panels``).
* **Tests.** Add a test next to what you change (:doc:`building`); the CI runs them on every
  pull request.

If you need VizMini2 under other terms (for example inside a closed product), see
:doc:`../help/contact`.
